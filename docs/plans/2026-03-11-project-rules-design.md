# Project Rules Design

**Goal:** Add a permanent Russian-language rules document for this Remotion project that is useful for both humans and AI agents.

**Scope**
- Create a new top-level `Rules` directory.
- Add one primary rules document rather than splitting guidance across many files.
- Cover both best practices and mistakes to avoid.

**Chosen Structure**
- `Rules/PROJECT_RULES.md`

**Document Sections**
- Project purpose and baseline principles.
- FPS and performance rules.
- Remotion-specific workflow rules.
- React / Three.js / 3D scene rules.
- Asset and preload rules.
- Animation and timing rules.
- Non-degradation design rules.
- Testing and verification rules.
- Build stability rules.
- Anti-patterns and pre-completion checklist.

**Tone**
- Practical, strict, and implementation-oriented.
- Short explanations, explicit do/don't guidance, concrete failure modes.
