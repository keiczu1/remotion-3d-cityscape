# Ranking Towers Monthly Metric Design

**Date:** 2026-03-11

## Goal

Сделать строку посещаемости визуально чище: убрать `.0` у целых сокращенных значений и вынести `Monthly` на отдельную строку без деградации дизайна карточки.

## Approved Direction

- Основное значение остается главным акцентом.
- Формат значения:
  - `915.0 M` -> `915 M`
  - `867.0 M` -> `867 M`
  - `3.2 B` остается `3.2 B`
- Слово `Monthly` переносится на вторую строку под числом.
- Вторая строка должна быть заметно слабее основного значения: меньший размер, мягче по opacity, но в той же визуальной системе.

## Constraints

- Не менять композицию карточки радикально.
- Не ухудшать читаемость числа.
- Не ломать scramble-анимацию числа.
- Не расширять строку значения горизонтально.

## Implementation Notes

- Изменение формата должно жить в helper, а не быть размазано по JSX.
- Значение и подпись нужно отрендерить как две отдельные `Text`-строки в dashboard.
- Тесты должны покрыть форматирование `.0` и добавление monthly label.
