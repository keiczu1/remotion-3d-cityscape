# Skill `justdoit`

Русскоязычный процессный skill для Codex, который превращает расплывчатую задачу в понятный пакет исполнения без лишней бюрократии.

## Что Он Делает

- всегда фиксирует воспроизводимый план;
- не дает чинить баги без понимания корневой причины;
- не дает менять поведение без явной проверки;
- требует свежую верификацию перед заявлением о завершении;
- подбирает нужную строгость процесса: `compact`, `standard` или `strict`.

## Что Появляется На Выходе

- `plans.md` почти всегда;
- `status.md`, если нужен ход выполнения и передача контекста;
- `test-plan.md`, если нужен отдельный контракт проверок.

## Ключевая Идея

Смысл `justdoit` не в том, чтобы всегда создавать максимум документов, а в том, чтобы дать минимально достаточный процесс без потери качества.
