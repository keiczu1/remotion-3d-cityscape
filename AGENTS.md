# Инструкции AGENTS.md для Remotion

## Назначение

Этот репозиторий является рабочей базой для производства роликов формата `ranking corridor` на `Remotion`, `React`, `@remotion/three` и `React Three Fiber`.

Система должна быть воспроизводимой только по файлам репозитория. Не полагайся на память прошлых чатов, скрытое глобальное состояние или устные договоренности.

## Язык общения

- Все ответы, вопросы, планы, пояснения, промежуточные отчеты и итоговые сообщения ИИ в этом репозитории должны быть только на русском языке.
- Исключения допускаются только для кода, команд, путей, URL, API, названий пакетов, ключей конфигурации и других технических сущностей, которые нельзя безопасно переводить.
- Если пользователь явно просит другой язык, можно ответить на нем только в пределах этого запроса.

## Дефолты сессии

- Считай репозиторий продакшн-базой `ranking corridor`, а не песочницей для хаотичного R&D.
- Работа по умолчанию должна укладываться в модель одного репозитория и одного окна IDE.
- Изоляция по умолчанию идет через `projects/<project-slug>/` внутри текущего репозитория.
- Не предлагай `git worktree` и не уводи работу в отдельный репозиторий, если пользователь сам этого не просил.
- Новый код, модули и элементы сцены по умолчанию должны сначала оставаться на уровне конкретного проекта, а не переноситься сразу в библиотеку.
- Перенос в библиотечный слой допустим только после финального утверждения проекта и отдельного ручного решения.
- Канонический формат видео по умолчанию:
  - `1920x1080`
  - `60 fps`
- Не спрашивай про разрешение, FPS и финальный файл, если пользователь явно не хочет другой формат.
- Целевой дефолтный результат: Studio-ready Remotion-композиция, которая корректно открывается и проверяется в Remotion Studio.
- Не рендери `.mp4`, `.mov` или другой финальный файл, если пользователь явно не попросил экспорт.

## Новый ролик по умолчанию

Для нового запроса по умолчанию используй простой маршрут:

1. Пользователь называет тему.
2. ИИ подбирает ближайший шаблон из template-catalog (`docs/library/ranking-corridor-template-catalog.md`).
3. ИИ запускает scaffold: `npm run scaffold:template -- <template-id> <project-slug>`.
4. ИИ заменяет данные в `data/` и адаптирует визуал под тему.
5. ИИ проверяет результат в Remotion Studio.

Если ни один шаблон не подходит, ИИ предлагает ближайший вариант и объясняет, что нужно адаптировать.

Полезные справочные материалы для выбора шаблона и компонентов:

- `docs/library/ranking-corridor-template-catalog.md` — 4 готовых шаблона
- `docs/library/ranking-corridor-constructor-catalog.md` — camera/hero/world пакеты
- `docs/library/ranking-corridor-module-registry.md` — реестр переиспользуемых модулей

## Структура проекта

По умолчанию используй такую схему:

- `projects/<project-slug>/` — project-container конкретного ролика.
- `src/compositions/<project-slug>/` — код композиции конкретного ролика.
- `public/ranking-corridor/<project-slug>/` — локальные публичные ассеты ролика.
- `src/lib/ranking-corridor/` — только для реально подтвержденных reusable-модулей после promotion.

Не переноси код в библиотеку заранее.

## Пользовательский UX

- Держи пользовательский интерфейс простым и разговорным.
- Не перекладывай на пользователя внутреннюю механику workflow, если в этом нет реального блокера.
- Не требуй длинного интервью там, где хватает одного пакета вопросов.
- Если приходится выбирать между reuse и novelty, проговаривай компромисс явно и кратко.

## Стиль ответов

- Отвечай кратко, по делу и в продакшн-режиме.
- Не дублируй большие куски канона прямо в ответах, если можно сослаться на владеющий документ и следовать ему.
- Если меняешь workflow, канон или библиотечный слой, обновляй связанную документацию вместе с изменением, а не задним числом.
