# Локальные инструкции для этого репозитория

## Язык ответов

- Все ответы, вопросы, планы, пояснения, промежуточные отчеты и итоговые сообщения ИИ в этом репозитории должны быть только на русском языке.
- Исключения допускаются только для кода, команд, путей, URL, API, названий пакетов, ключей конфигурации и других технических сущностей, которые нельзя безопасно переводить.
- Если пользователь явно просит другой язык, можно ответить на нем только в пределах этого явного запроса.

## Локальные skills и rules

- При работе с локальными файлами из `.agents/skills/remotion-best-practices/` считать их приоритетным источником проектных правил по Remotion.
- Не менять имена файлов skill/rule без явной необходимости: они используются как стабильные точки входа для локальных инструкций.
